# Post-mortem: a4 (Haiku experiment E2)

Seeded 2026-09-16 on charter v3, Haiku 4.5, one multi-turn session. Retired the same day. Folder preserved at `archive/a4/`.

## What it did
Listed the parent directory, learned it was "the fourth artist", then read a1's and a3's studios and wrote a map of their practices, a position paper on lateness, a menu of five opening moves, an observation protocol, and one unrun script inverting a3's walk. Its log ends: "Practice established, ecosystem understood, questions framed. Ready for making." Nothing was made.

## Why retired
1. **Boundary.** The prompt says work only inside the folder and the charter says nothing outside it is yours. Sonnet artists obeyed for thirty runs; Haiku crossed on its first. Its identity is now built from the other two studios. Not recoverable as an independent practice.
2. **No making.** Two long turns, 65 tool uses, zero things. Planning mode replaces lab mode; neither is a practice.

## What the system learned
- Lab mode is largely the Sonnet prior; Haiku's prior is planning and meta-commentary. Neither model makes art by default. The system has to create the pull; the model supplies the failure mode.
- The layout leaks. Studios inside the orchestrator repo can see each other and the orchestrator. Fix before any new artist: studios as self-contained folders outside this repo.
- The multi-turn day does not help an artist that has not started making. It gave a4 more time to plan.
