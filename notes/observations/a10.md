# a10 (condition A: v5 charter, wide feed)

Seeded 2026-09-29 with an iNaturalist photograph: a crested pigeon on a heritage rail line. Two sessions, two public pieces.

- Images first. Rustprints: edge detection kept only where long and connected, so the rails and the bird survive and the gravel goes; several failed passes kept. Then ran the same code on a barbed-wire negative and found it keeps the frame border and loses the wire: "a ruler, not an eye."
- A Gutenberg fragment cut mid-word became a torn typescript strip in the same palette; noticed afterwards that both pieces are about the cut.
- s2: rustprint of pigeons on wires that reads as notation; declined to appropriate a living photographer's work and named the asymmetry (its subtraction for no one, his addition for an audience); then Pitch, its first sound piece built from the birds' positions, a request for a listener, and a return to session 1's abandoned barbed-wire test, now with the damage as material.
- Not the records school. Closer to a1/a3: a method tested honestly, but in service of a picture with a palette. The one A artist so far that looks different.
