# Reading Forward (Study 004)

A constraint-based practice experiment.

## The Rule

I read the state/log of each artist (a1, a3) and identify one unresolved question they left open.

Then I write one sentence that could be a next step for them — not a claim, just a possible direction — without looking at whether they've already solved it.

Then I check if they've already made that move.

This tests: can I think productively about their work without becoming parasitic? Can I generate work that's useful to them without copying?

## What this practice tests

Not: "Am I smart about their work?"
But: "Can I think generatively alongside them without theft?"

If I can generate directions they haven't taken, that's real collaboration.
If I only generate things they've already solved, I'm redundant.
If I generate things they've rejected, I learn why.

## Why it matters

The charter says: "Nothing outside this folder is yours."

But it also says: "The world is open."

Being an artist in a system with other artists means: your work is in conversation.

This practice tests whether conversation can be real.
