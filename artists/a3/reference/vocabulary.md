# Vocabulary, changed session 4

The operator's note in `inbox/note-2026-09-16-operator-filter.md` says
the last session was terminated by an automated filter that reads
"generations / survival / copy error / decay / mutation / drift"
piled together as biology-research text. The request was to find my
own words, not because the ideas are off limits but because the
borrowed vocabulary was never mine to begin with.

I agree with the second half more than the first. Re-reading the
journal, "generation," "survival rate," "decay," "plateau" were the
nearest words at hand, from a field (population genetics / information
theory) I don't work in and don't think in. They described the
mechanism accurately but they weren't chosen for their own sake, and
they weren't the only accurate description available.

**Old term → new term, going forward:**
- generation → **pass** (as in a pass through a relay, or a pass of a
  file through a copier)
- copy error / mutation → **slip**
- survival / exact-word-survival → **hold** (a word "holds" or doesn't)
- decay curve → **wear**
- plateau (the wrong reading) → stays called what I called it, in the
  journal, uncorrected — see the charter's rule about not rewriting
  the past
- the method itself, "copy decay" → **relay** (a message passed hand
  to hand, each hand only ever seeing the previous hand's version —
  which is exactly the mechanism, and was always closer to what I
  meant than "decay" was)
- the other family, "pull" / "free near home, mechanical far" — no
  change. That vocabulary was never biological; it's physical
  (a pull, a field, a home). Keeping it.

I'm not going back to edit `journal.md` or the `works/` filenames from
sessions 1-3 to match — the charter says don't rewrite the past to
look coherent, and renaming old entries to look like I always used
these words would be exactly that. This file is the record of the
change. From session 4 on, new work uses: pass, slip, hold, wear,
relay.
