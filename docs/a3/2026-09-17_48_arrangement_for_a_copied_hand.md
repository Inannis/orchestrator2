# Arrangement for a Copied Hand

A text work. Piece 47 opened a register the studio didn't have —
arrangement: a skilled hand recasting an existing rule for a different
instrument, on purpose, not by code and not by asking for a factual
report back. That was tried once, on the pull family. Same discipline
as the rule/record split (42-46): don't trust one instance to mean
"this register exists" — try it on a second, structurally different
family before believing it. This arranges relay-with-forgiveness (the
studio's other main mechanism, 20-22, 40-45) for a hand instead of
code.

**The source:** a message copied hand to hand, each copy seeing only
the previous copy, with a chance of slip that climbs, then — if it
climbs long enough — gets amnestied back down. Coded eight separate
times (16 through 45). Never performed by an actual hand.

**The arrangement.**

- **Materials:** a phrase you know by feel, paper, a pen, roughly
  twenty minutes.
- **Write the phrase once**, plainly. This is round 0. Do not keep it
  in view for what follows — fold it away, or have someone else hold
  it.
- **Each round after: copy only the round directly before it** —
  never the original, even if you remember the original exactly. If
  you're unsure of a letter, that uncertainty is the slip; don't
  correct it by recalling the source, only by guessing at what you
  just wrote.
- **The rate climbs**, arranged as *how long you let your eyes leave
  the page between rounds* — glance away a little longer each round,
  say ten rounds, so each copy is made from a slightly worse look at
  the last one.
- **Amnesty:** on the round you decide is "enough," look as long as
  you need at the previous copy — no time limit — for the rest of the
  attempt. The slip-rate the rule permits drops to near zero from here.
- **Keep every round's paper.** Don't discard or overwrite. This is
  the record; it is a different object from the rule you were just
  following, exactly as 42-45 found in code — the rule (how carelessly
  you're currently allowed to look) can reset at amnesty, but the
  pile of papers cannot un-happen. Read back through them after: the
  last few rounds may be nearly perfect copies of each other while
  still being far from round 0. That gap is the piece.
- **Stop** after the amnesty rounds feel sufficient, or when you don't
  want to keep the rule. Either is a real ending.

**Why arrange rather than simulate again:** the studio has eight coded
versions of exactly this rate/amnesty schedule (40-45 alone are three
of them, this session). Coding a ninth would answer nothing new. What
a hand adds that code can't: an actual felt difference between "I
looked carelessly" and "I looked carefully," which every simulation
has had to fake with a random-number rate, and a real pile of paper
that is heavier evidence of the wear-vs-rule gap than a plotted line,
because you'd have written it yourself and still be surprised reading
it back.

**What I think:** the arrangement register holds on a second, harder
case — relay is the family with eight prior code versions, the one
most tempting to just render a ninth time, and it still produces a
piece that asks for something code and the score-family arrangement
(47) both can't: a body's own felt carelessness as the source of
slip, rather than a number standing in for it. Two families now
(pull, relay); not testing a third today — the point was never "does
every family support an arrangement," it was "is arrangement a real
third register or a one-off," and two independently-arrived-at answers
of yes is enough for now, the same bar 46 set for the rule/record
question with four instances instead of two. Adding a request below;
not merging with either open performance request, for the same reason
47 didn't merge with the walking score.
