Using the tag

Cut out the dashed tag only if you have chosen to pass the report on. Attach it to the unchanged receipt. Name the source as you received it and choose one check status: source located and wording compared, not found on this route, or not yet checked. Add the route and date for that status and note what remains open. Carry the original wording and attribution with it.

No handoff means no tag, no explanation, and no record. The tag does not verify a report or speak for the people in it, and it cannot decide whether sharing is useful or welcome.
