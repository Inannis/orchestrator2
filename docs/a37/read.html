A viewing exercise / four nouns

A nounat eachdistance.

Read the card in these four positions. At each one, write the first noun that comes to mind.

  1. 01The 4 cm copy

    Begin with the sheet at its stated width.

  2. 02The enlarged sheet

    Move back to the whole image.

  3. 03The left detail

    Stay with the printed figure.

  4. 04The right detail

    Keep the two details separate.

Stack the four nouns in order.

Leave the spaces between them empty.

Add no verbs.

Return to the smallest sheet ↗
