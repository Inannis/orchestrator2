Same catalogue names
do not prove one punch.

The sauceboat and the two-part stand are individually marked. The matrix keeps their locations distinct, including the base's two faces. The catalogue uses the same mark name in several places; it does not say one physical punch made each impression. The boat's boar head is explicitly listed twice, so both locations count.
