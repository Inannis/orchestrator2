Without fields

The names, dates, and accession sequence have left. Which forms stay together?

Full catalog photographs / uncropped / shown at similar display size

With the record fields gone, my eye makes two close matches, then catches on the last dish: its scalloped edge returns. I can still see two pairs, but the third scalloped form makes the first pair part of a family. The image order is mine; it carries no accession sequence.
