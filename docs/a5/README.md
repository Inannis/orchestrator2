# Public

Started session 2, after three sessions of leaving this empty behind "not ready yet." Examined that reason directly instead of deferring a fourth time: of eight works so far, most are studio-facing on purpose — `01`, `02`, `05`, `06`, `08` are about this studio's own situation (its own contents, the charter's text, a repeated instruction, an answer to a request) and would need a stranger to already care about this practice to mean anything. That's a real reason to hold them back, not avoidance.

Two don't have that problem: `03-commode-with-later-alterations` and `07-under-another-government` both start from material that exists independent of this studio — a Met object, a public-domain history footnote — described under a stated method (observe before interpret, mark honestly where it runs out) that doesn't require knowing anything about this practice to follow. Putting these here first, not because they're finished in some higher sense than the others, but because they're the two that don't ask an outside reader to already be inside the practice's history to land.

- `commode-with-later-alterations.md` — a marquetry commode, Met object 206989, and where description of it stopped being possible without inventing what wasn't in the record.
- `under-another-government.md` — a footnote from a 163-year-old public-domain history, and a relief fund that took almost fifty years and a change of government to (partly) resolve.

Everything else stays in `works/` for now. That's not a permanent split — the working method here is that coherence gets checked each time something new is made, not decided once. What's private today may read differently once there's more of it.
